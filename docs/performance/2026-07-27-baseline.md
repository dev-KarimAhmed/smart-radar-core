## Method

The production application was built with:

```powershell
.\..\..\node_modules\.bin\next.cmd build
```

The production server ran locally on port 3100. Lighthouse used a fresh temporary Chrome profile for each URL, mobile form-factor emulation, the Performance category, and headless incognito Chrome:

```powershell
npx.cmd --yes lighthouse@12.8.2 <URL> `
  --chrome-path="C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --output=json `
  --only-categories=performance `
  --form-factor=mobile `
  --screenEmulation.mobile=true `
  --chrome-flags="--headless --no-sandbox --disable-gpu --incognito" `
  --quiet
```

The user-provided DevTools screenshot showed a Performance score of 33 and warned that IndexedDB data affected that run. That screenshot is retained as contextual evidence only; the reproducible clean-profile measurements below are the engineering baseline.
